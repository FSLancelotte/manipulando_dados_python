# Estatística com python
Conhecimentos básicos de estatística são essenciais para analistas de dados porque permitem a 
compreensão e interpretação correta dos dados. Funções estatísticas como média, mediana, variância
e desvio padrão ajudam a resumir e descrever os dados, enquanto conceitos como correlação e regressão
são fundamentais para identificar e modelar relações entre variáveis.

## Explicação dos arquivos presentes nesta pasta
- **estatistica_basica.py:**
Script voltado para relembrar conceitos básicos de estatística e ilustrar o uso
de pandas e numpy
- **correlacao_dados.py:**
Script focado em métodos para verificar correlação de variáveis
- **modelo_regressao.py:**
Aplicação de um modelo de regressão linear simples para prever valores de uma variável, utilizando 
pandas e sk-learn
- **modelo_classificacao.py:**
Aplicação de Árvore de Decisão e Regressão Logística para classificação de dados
- **aplicacao_dados.py:**
Aplicação dos modelos criados nos scripts de modelos para predizer valor e classe de uma variável a 
partir de dados novos
- **clientes-v3-preparado.csv:** 
Arquivo CSV com os dados preparados para utilização nas aulas como objeto de estudo
- **modelo_regressao_linear.pki:**
Arquivo que salva o modelo de regressão linear gerado no script *"modelo_regressao.py"*
- **modelo_regressao_logistica.pki**
Arquivo que salva o modelo de regressão logística gerado no script *"modelo_classificacao.py"*
- **modelo_arvore_decisao.pki**
Arquivo que salva o modelo de árvore de decisão gerado no script *"modelo_classificacao.py"*

## Correlação entre variáveis
Duas variáveis podem se correlacionar de maneira positiva ou negativa (enquanto
uma cresce a outra cresce ou diminui) e essa relação pode ser forte ou fraca,
gerando uma representação gráfica de reta quando é forte ou uma dispersão
quando é fraca.
