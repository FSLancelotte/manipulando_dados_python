# Estudo de manipulação de dados em python
Este repositório tem como intuito organizar e documentar o estudo dos módulos voltados para maipulação de dados com Python do curso da EBAC de Análise de Dados.

## Conteúdos dos Módulos
- **Coleta_Dados:**
  - Web Scraping com Beautiful Soup
  - Coleta de Dados através de API
  - Integração com MySQL e Manipulação de Dados
- **tratamento_dados:**
  - Exploração Inicial dos Dados (entender a estrutura, tipos de dados e presença de valores nulos)
  - Limpeza de Dados com Pandas
  - Identificação e Tratamento de Outliers e Dados Inconsistentes
- **preparacao_dados:**
  - Transformação e categorização de dados para facilitar análises futuras
  - Padronização e Normalização
  - Codificação de Variáveis Categóricas
 
  ## Lidando com outliers no Tratamento vs Preparação 
  Ambos os processos lidam com outliers mas com um viés diferente.
  Durante o tratamento o foco é em remover os dados que são errados.
  O processo de preparação lida com outliers que são dados reais mas
  que podem atrapalhar na análise ou no aprendizado de um modelo (Machine
  Learning)
