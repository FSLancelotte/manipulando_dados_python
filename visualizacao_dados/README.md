# Visualização de Dados


## Explicação dos arquivos presentes nesta pasta
- **intro_visualizacao.py:**
Script de introdução ao módulo, ilustra com exemplos simples o uso das
bibliotecas *"matplotlib"* e *"seaborn"* para plotar gráficos
- **uso_matplotlib.py:**
Estudo voltado na biblioteca matplotlib, realizando a plotagem de gráficos
de barras, pizza e dispersão
- **uso_seaborn.py:**
Estudo voltado na biblioteca seaborn, realizando a plotagem de gráficos
- **exemplos_graficos.py:**
Aplica técnicas de visualização de dados para realizar o agrupamento
de dados e analisar a contagem de diferentes categorias
- **clientes-v3-preparados.csv:**
Arquivo csv que contém os dados a serem utilizados para geração de gráficos
nos scripts python
- **meu_grafico.png:**
Arquivo de imagem salvo a partir da plotagem de gráfico no script 
*"exemplos_graficos.py"*
